# Nudge Sense

Voice of Customer dashboard for **Samsung Now Nudge** (Galaxy AI): what people say about the feature across Samsung's communities, Reddit, X and the press.

- **Dashboard:** `dashboard/index.html` (live via GitHub Pages)
- **Design system:** `dashboard/design-system.html`
- **Method:** `VOC-Method.md` · **Feature background:** `Feature-Background.md`
- **How runs work:** `AGENT-UPDATE-GUIDE.md` (runs are incremental: each collects only what was posted since the previous run)

**Install on your phone:** open https://karthikeya-gs07.github.io/nudge-sense/dashboard/ — on Android (Chrome / Samsung Internet) choose *Install app* or *Add to Home screen*; on iPhone (Safari) tap Share → *Add to Home Screen*. It opens full screen and shows the last loaded data when offline.

All quotes are copied verbatim from public posts; usernames are not stored.
